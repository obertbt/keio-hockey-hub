# 日報の書き方と、コーチとのやり取り

**書く項目は8つだけです。全部埋める必要はありません。**

---

## 前と何が変わったか

| 前                                    | いま                               |
| ------------------------------------- | ---------------------------------- |
| 記述欄が10、段階評価が5               | **記述欄4、段階評価2、目標、質問** |
| 「もう少し詳しく書く」を開くと更に5つ | 無くなりました                     |
| 質問は動画からしか出せなかった        | **日報からコーチを呼べる**         |
| コーチの返事が読まれたか分からない    | **読むまで「今日」から消えない**   |

### なぜ減らしたか

必須はひとつも無かったのですが、**並んでいるだけで「全部書くもの」に見えます**。
毎日のものなので、見えている量がそのまま負担になります。

**過去に書いたものは消えていません。**
入力欄から外しただけで、以前の日報を開けば、書いたものはそのまま出ます。

---

## 書く（選手）

**今日** → **日報を書く**、または下の **日報**。

| 順  | 項目                 | 書き方                                     |
| --- | -------------------- | ------------------------------------------ |
| 1   | 中目標               | **押すだけ。**今日取り組んだものを選びます |
| 2   | できたこと           | ひとことで構いません                       |
| 3   | 反省点               | 無ければ空で構いません                     |
| 4   | 次回に向けた取り組み | 次の練習の目標にそのまま使えます           |
| 5   | 自己評価             | 1〜5                                       |
| 6   | 疲労度               | 1〜5                                       |
| 7   | 自由記述             | 任意                                       |
| 8   | 質問                 | **聞きたいことがある日だけ開きます**       |

**ひとつでも書いてあれば提出できます。**
何も書けない日は、下書きとして保存しておけます。

### 質問する

いちばん下の **コーチに聞きたいことがある** を押すと開きます。

```
質問       持ち出しのとき、右足からのほうがいいですか
誰に聞くか  [ 山田コーチ ] [ 佐藤コーチ ]
```

**誰も選ばなくても書けます。**
選ぶとその人に知らせが届きます。選ばなくても、コーチの画面には出ます。

聞かない日は、開かなくて構いません。

---

## 返事を読む（選手）

コーチが返すと、**今日** の画面にそのまま出ます。

```
コーチからの返事が 1 件
読んだら「読みました」を押してください。

  山田コーチ  2026年8月13日の日報
  右足で構いません。半歩前で受けてみましょう
```

押して日報を開くと、いちばん上に **読みました（1件）** があります。

### なぜ押させるのか

**開いただけを「読んだ」にはしていません。**

開いた＝読んだ、にすると、通知を消すために開いただけの日も
コーチには「届いた」と見えます。
コーチは返した言葉が届いたと思って次を書き、選手は読んでいない。
**いちばん大事な信頼が、誰にも気づかれないまま壊れます。**

だから押してもらいます。押すまで「今日」から消えません。

**返事は書かなくて構いません。** 押すだけで閉じられます。
返す言葉が思いつかない日に、読むこと自体をやめてしまうほうが困るので。

### 会話を続けたいとき

各コメントの下に **返信する** があります。
返信は1段だけです。返信への返信はできません（同じコメントに返してください）。

枝分かれすると、何への返事か追えなくなるためです。
動画の掲示板とまったく同じ形にしてあります。

---

## 返す（コーチ）

**今日** → **日報の提出状況** → 選手の日報を開く → **コメントする**。

書いた言葉は、**選手が「読みました」を押すまで未読のまま残ります**。
押されたかどうかは、その日報を開けば分かります。

### コーチにできないこと

**「読まれたことにする」はできません。**

これは画面に出していないだけでなく、データベース側でも止めてあります。
関数（`acknowledge_report_feedback`）だけが通り道で、
その中で「日報を書いた本人か」を確かめています。

実際、作っている途中で**コーチが直接書き換えられる穴が開いていました**。
テストで見つけて塞いでいます（`report_thread_test.sql`）。

## 誰に見えるか

| 見る人           | 日報の中身                       | やり取り       |
| ---------------- | -------------------------------- | -------------- |
| 自分             | 見える                           | 見える・書ける |
| コーチ・スタッフ | 公開範囲が「コーチまで」以上なら | 同上           |
| ほかの選手       | 公開範囲が「部内全員」のときだけ | **書けない**   |

**「自分だけ」にした日報には、コーチもコメントできません。**
「自分だけ」は「コーチにも見せたくない」という意思表示なので、そこは守ります。
自分用のメモとして、本人が書き足すことはできます。

意見がほしくなったら、公開範囲を「コーチまで」に変えてください。

---

## 「今日」に出るもの（選手）

残っていることは、この順で出ます。

| 順  | 何が出るか                     | なぜその順か                     |
| --- | ------------------------------ | -------------------------------- |
| 1   | **コーチからの返事を読む**     | 待たせているのはこちら           |
| 2   | コンディション・目標・日報など | その日の記録                     |
| 3   | まだ記録に付けていない目標     | 急がない。思い出すきっかけとして |

返事を読むのがいちばん上なのは、**返事を待たせているのは選手の側だから**です。
