# 目標の使い方

**大分類はチームで決まっています。その下は、自分の言葉で書きます。**

コーチの承認は要りません。書いたらそれで登録されます。

---

## 前と何が変わったか

| 前                                   | いま                                   |
| ------------------------------------ | -------------------------------------- |
| 大分類 → 中目標 → 小目標 の3段階     | 大分類 → 中目標 の**2段階**            |
| 小目標はコーチが全員ぶん用意する     | **中目標は各自が書く**                 |
| 「できた」は申請してコーチが承認する | **「できた」は自分で押す**             |
| 到達度（%）で見る                    | **何回向き合ったか**で見る             |
| 一度決めた目標は変えにくい           | 名前も分類も、あとから自由に変えられる |

### なぜ変えたか

3段階めを誰が書くのかが決まりませんでした。
コーチが全員ぶん書けば、その人の言葉ではなくなります。

そして「できるようになった」を人に認めてもらう手続きが要ると、
出すのが怖くなります。出せないものは記録に残りません。

到達度（%）も外しました。
承認の数を追いかけると、**承認されにくい目標を書かなくなる**ためです。
代わりに「その目標に何回向き合ったか」を数えます。
これは誰の判断も待たずに増えていきます。

## 選手の使い方

### 1. 目標を書く

**目標** を開いて **目標を書く** を押します。

| 入れるもの                   | 例                                 |
| ---------------------------- | ---------------------------------- |
| 目標                         | 持ち出しを速くする                 |
| どうなったらできたと言えるか | 相手に寄せられる前に、前を向けたら |
| 大分類                       | 止める・蹴る                       |

**大分類は決めなくても書けます。**「まだ分けていない」のままで構いません。
あとから移せます。

**あとから全部直せます。** 名前も、説明も、大分類も。
直せることが分かっていないと、最初の1つを書くのが重くなるので、そうしてあります。

### 2. 日報を書くときに、目標を選ぶ

日報の「次回取り組むこと」の下に、目標が並びます。
**今日取り組んだものを押すだけ**です。

選ばなくても日報は出せます。選ぶために止まらないでください。

出てくるのは**取り組み中のものだけ**を、**しばらく触れていない順**に、8つまで。
よく使う順にすると、同じ目標ばかりに寄っていくためです。

### 3. 動画に書き込むときにも選べる

動画の書き込み欄にも「どの目標の話か」が出ます。同じように押すだけです。

### 4. 積み上がりを見る

**目標 → その目標を押す** と、こう出ます。

```
持ち出しを速くする
取り組み中   12回

この目標に付けた記録
  2026年8月13日   3対2で、2回は前を向いてから運べた
  2026年8月11日   持ち出しが遅くて、相手に寄せられた
  動画への書き込み  ここで半歩前に出られたら
```

押すと、その日報や動画のその場面へ飛びます。

### 5. できるようになったら押す

同じ画面の **できるようになった** を押します。
**コーチの承認は要りません。**

押しても消えません。一覧の下のほうに、回数と一緒に残ります。
積み上がったものが見えることが、続ける支えになるからです。

間違えて押しても、もう一度押せば戻ります。

---

## 似た目標を2つ作ってしまったとき

「持ち出し」と「持ち出しを速く」を別々に作ってしまう、が必ず起きます。

片方を消すと、そこに積み上がった回数が失われます。
そうならないよう **まとめる** があります。

**目標 → 片方を押す → まとめる・消す → ほかの目標にまとめる**

付いていた記録が全部あちらへ移ってから、こちらが畳まれます。
**回数は失われません。**

消すのは、まだ何も付けていない目標のときだけにしてください。

## 誰に見えるか

| 見る人           | 見えるか             |
| ---------------- | -------------------- |
| 自分             | 見える。直せる       |
| コーチ・スタッフ | **見える。直せない** |
| ほかの選手       | **見えない**         |

コーチには見えるようにしてあります。
何に取り組んでいるかを知らずに返す言葉は、その人に向いたものにならないためです。

**コーチでも、あなたの目標を書き換えることはできません。**
「できるようになった」を押すこともできません。
自分の目標を人に書き換えられると、自分のものでなくなるためです。

## コーチの使い方

### 大分類を決める

**大分類**（`/admin/skills`）で、チームの大分類を作ります。

これだけがコーチの仕事です。**その下は各自が書きます。**

大分類は、広めに作ってください。
細かく切ると、選手が「どこにも当てはまらない」と感じて書かなくなります。

### 審査は無くなりました

スキル申請の審査はもうありません。「今日」からもその枠が消えています。
**待たせているものが1つ減りました。**

代わりに見るのは、日報のコメントと、動画の返事待ちの書き込みです。
どちらも「今日」に出ます。
